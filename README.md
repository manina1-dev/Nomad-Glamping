# Nomad Glamping

Στατικό site παρουσίασης (HTML / CSS / JavaScript, χωρίς build).

- `index.html` — περιεχόμενο (ελληνικά, με αγγλικά στα `data-en`)
- `css/style.css` — εμφάνιση
- `js/main.js` — εναλλαγή γλώσσας, μενού, lightbox φωτογραφιών
- `assets/photos`, `assets/thumbs` — φωτογραφίες (μεγάλες και μικρογραφίες)

## Τοπική προεπισκόπηση

```bash
python3 -m http.server 8000
```

## Δημοσίευση στο GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → επιλέξτε branch και φάκελο `/ (root)`.
